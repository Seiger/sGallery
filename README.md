# sGallery documentation site

This branch contains the Docusaurus site and the GitHub Pages workflow. The published guides are read from `docs/<locale>/` on each configured package branch. dDocs reads the same Markdown and `docs.json` from the installed package.

## Build locally

Use Node.js 22 or later. From this site checkout, point the builder at a package checkout that contains the canonical documentation:

```sh
npm ci
npm test
npm run test:build
npm run docs:prepare -- 1.x=../sGallery-docs-1x
npm run build
npm run serve -- --port 3018
```

Open `http://localhost:3018/sGallery/` or `/sGallery/uk/`. Use `npm start -- --locale uk` for one locale during editing. The production build checks the links for all configured languages.

CI checks out the canonical documentation from each branch in `docs.config.json` and builds the linked trees in `.generated/`. Keep translations on the package branch so dDocs and the site see the same content.

## Add a new major line

After the new package branch has its own canonical documentation, add it to `docs.config.json` as `current`. Change `1.x` to `legacy` or `previous` as appropriate. The current line starts at `/sGallery/`. An older line appears at `/sGallery/1.x/` and, for example, `/sGallery/uk/1.x/`. Commit the configuration change with the site shell. The version menu, checkout matrix and paths follow the registry.

## Publish on GitHub Pages

Set the Pages source to **GitHub Actions**. The reusable workflow lives on the `docs` branch. The caller on each package branch starts it when guides change. Both branches need to be on GitHub before the first successful deployment. If the `github-pages` environment limits deployment branches, allow the site branch and its package callers. Run the workflow and check the deployment URL before announcing the switch.

The site keeps the `/sGallery/` base URL and existing article paths, including `getting-started/`, `configuration/`, `use-in-blade/`, `background-image-optimization/` and `manipulations/`. The old search page redirects to the documentation home. The sitemap is generated by Docusaurus.

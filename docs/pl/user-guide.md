# Przewodnik redaktora

Otwórz zasób i galerię w panelu Evolution CMS. Prześlij zdjęcie, wybierz plik z biblioteki, jeśli pozwala na to rola, lub dodaj link YouTube. Przeciągnij elementy w wybranej kolejności.

W formularzu edycji wpisu zmienisz tekst alternatywny, tytuł, opis lub link. Uzupełnij odpowiednie zakładki językowe. Odłączenie wspólnego pliku zachowuje oryginał w bibliotece.

Jeśli zakładka albo przycisk są niedostępne, sprawdź szablon oraz [uprawnienia](./configuration.md).

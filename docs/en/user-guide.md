# Editor guide

## Add and order media

1. Open the resource in the Evolution CMS Manager, then open its gallery tab or the named block assigned to its template.
2. Select a local image or add an existing file from the Manager file browser if your role allows it. Use the YouTube action for a video link. Download controls are available in integrations that expose a downloads section.
3. Drag the items into order. Use the preview to check an image before saving its text or link.

## Edit and remove items

Open an item's edit form to update its alternative text, title, description or link. Edit the available language tabs when the site uses sLang. Use a meaningful alternative text for images that carry content.

Deleting an uploaded gallery item removes its owned file. Removing a reference to a shared library file leaves the library original in place.

If the gallery tab or an action is missing, check the [template assignments and Manager permissions](./configuration.md#manager-gallery-permissions).

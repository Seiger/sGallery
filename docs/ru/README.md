# О sGallery

sGallery добавляет галереи к ресурсам Evolution CMS и модулям, таким как sCommerce. Редактор может прикрепить изображения, файлы для скачивания и видео YouTube, изменить порядок и заполнить подписи на разных языках.

Builder генерирует миниатюры, WebP и AVIF с помощью GD или Imagick. Spatie Image и sTask подключаются по необходимости.

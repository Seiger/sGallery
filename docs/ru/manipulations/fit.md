# Подгонка

`fit($method, $width, $height)` задаёт способ подгонки под рамку в пикселях. Если высота пропущена, она равна ширине.

```php
$url = sGallery::file($item->src)->fit('max', 500, 300)->getFile();
```

| Режим | Результат |
| --- | --- |
| `contain` | Вписывает изображение в рамку с сохранением пропорций. |
| `max` | Вписывает без увеличения. |
| `fill` | Вписывает без увеличения и заполняет поля. |
| `stretch` | Задаёт точные размеры с возможным изменением пропорций. |
| `crop` | Заполняет рамку и обрезает лишнее. |
| `fill-max` | При необходимости увеличивает изображение и заполняет поля. |

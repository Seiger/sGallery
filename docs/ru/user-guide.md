# Руководство редактора

Откройте ресурс и вкладку галереи в менеджере. Загрузите изображение, выберите файл из библиотеки при наличии прав или добавьте ссылку YouTube. Расставьте записи перетаскиванием.

В форме редактирования можно изменить альтернативный текст, заголовок, описание и ссылку. Заполните нужные языковые вкладки. При удалении ссылки на общий файл оригинал остаётся в библиотеке.

Если вкладка или действие недоступны, проверьте [шаблон и права](./configuration.md).

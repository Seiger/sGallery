# Довідник

## Формати

Підтримка залежить від кодеків, із якими зібрано PHP-розширення.

| Формат | GD | Imagick |
| --- | --- | --- |
| JPEG, PNG, GIF, WebP, AVIF | Читання й запис | Читання й запис |
| BMP | Читання | Читання |
| Односторінковий TIFF | | Читання |
| Статичні HEIC / HEIF | | Читання з Fileinfo та декодером HEIF |
| Статичний JPEG XL | | Читання з декодером JPEG XL |

Для перетворення анімованих GIF і WebP потрібен Imagick. Якщо кодек або операція недоступні, Builder може повернути URL оригіналу. `format('original')` зберігає розширення за наявності кодера для цього формату.

## Методи Builder

| Метод | Призначення |
| --- | --- |
| `collections()`, `documentId()`, `itemType()`, `blockName()`, `lang()`, `get()` | Вибірка записів за ресурсом, блоком і мовою |
| `file()`, `getFile()` | Джерело зображення й URL результату |
| `resize()`, `fit()`, `crop()` | Розміри, підгонка й обрізання |
| `manualCrop()`, `focalCrop()` | Вибір ділянки за координатами джерела |
| `format()`, `quality()`, `optimize()` | Формат, якість і оптимізація |
| `watermark()`, `sharpen()` | Водяний знак і різкість |

Детальні приклади наведено в [посібниках з обробки зображень](./manipulations/index.md).

# Налаштування

## Шаблони та блоки

Менеджер записує налаштування в `core/custom/config/seiger/settings/sGallery.php`. Якщо файла немає, діють типові значення з `config/sGallerySettings.php` пакета. Налаштування проєкту замінюють типові призначення шаблонів.

```php
<?php return [
    5 => ['slider', 'top-sales'],
    1,
    3,
];
```

Шаблон 5 отримує дві іменовані вкладки, а шаблони 1 і 3 — стандартну галерею. Іменовані призначення ставте перед окремими ID, щоб не отримати однакові числові ключі масиву. Старий вкладений запис `[1, 3, [5 => ['slider']]]` підтримується. Після редагування й збереження налаштувань sGallery менеджер записує плоский формат.

## Права менеджера {#manager-gallery-permissions}

Для дій із галереєю потрібні сесія менеджера й доступ до ресурсу. Читання вимагає `view_document` або `edit_document`. Для додавання, упорядкування й перекладів потрібні `edit_document` і `save_document`, для видалення додатково — `delete_document`. Стандартний блок має ім’я `1`.

Для власного типу, наприклад `product`, зареєструйте перевірку в `itemPolicies`:

```php
'itemPolicies' => [
    'product' => [\App\Gallery\ProductPolicy::class, 'allows'],
],
```

Політика отримує `($action, $parentId, $block, $evolution)` і повертає `true` для дозволеної дії. Список дій: `read`, `upload`, `uploadDownload`, `register`, `addYoutube`, `reorder`, `translate`, `delete`. Без політики власний тип доступний адміністраторам.

Додавання з файлової бібліотеки вимагає `file_manager` або відповідного дозволу `assets_images` чи `assets_files`. Файл має бути в `rb_base_dir` і, якщо задано, у `image_base_upload_dir`. Відв’язування спільного файла зберігає оригінал у бібліотеці.

## Формати, водяні знаки й кеш {#watermarks}

У **Конфігурація системи → sGallery** можна вибрати формат і якість зображень, різкість, оптимізацію, каталог кешу та типові параметри водяного знака. Збереження записує лише змінені налаштування.

Builder застосовує водяний знак після обробки зображення, коли викликано `watermark()`. Можна вказати локальний файл і параметри, передати лише параметри або використати типовий файл і параметри.

```php
$url = sGallery::file($item->src)
    ->fit('crop', 800, 800)
    ->watermark('assets/images/mark.png', ['width' => '20%', 'opacity' => 80])
    ->getFile();
```

Типовий каталог похідних файлів — `assets/cache/`. Після зміни `imageCacheDir` виконайте `php artisan vendor:publish --tag=sGallery` з каталогу `core`. Очищення кешу в менеджері видаляє індексовані похідні файли sGallery й зберігає оригінали. Перелік форматів наведено в [довіднику](./reference.md).

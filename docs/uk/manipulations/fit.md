# Підгонка

Метод `fit($method, $width, $height)` задає спосіб підгонки під рамку в пікселях. Типове значення висоти дорівнює ширині.

```php
$url = sGallery::file($item->src)->fit('max', 500, 300)->getFile();
```

| Режим | Результат |
| --- | --- |
| `contain` | Зберігає пропорції й уміщує зображення в рамку. |
| `max` | Уміщує зображення в рамку без збільшення. |
| `fill` | Уміщує без збільшення й заповнює порожні краї. |
| `stretch` | Надає точні розміри, пропорції можуть змінитися. |
| `crop` | Заповнює рамку й обрізає зайві краї. |
| `fill-max` | Уміщує в рамку, за потреби збільшує та заповнює краї. |

Для кадру за позицією або координатами використовуйте [обрізання](./crop.md).

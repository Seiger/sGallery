# Вирішення проблем

| Симптом | Що перевірити |
| --- | --- |
| У ресурсу немає вкладки | [ID шаблону в налаштуваннях](./configuration.md). |
| Редактор не може додати або видалити фото | [Права на дію й доступ до ресурсу](./configuration.md#manager-gallery-permissions). Для товару перевірте також політику інтеграції. |
| На сайті видно оригінал | Підтримку кодека й потрібного формату. Для великого або повільного перетворення перевірте [runner sTask](./background-image-optimization.md). |
| Файл відхилено | Тип вмісту, розширення й дозволені завантаження CMS. Для бібліотеки врахуйте її налаштування і права. |
| Composer зупинився на PHP 8.6 | Збірку ядра зі [виправленням встановлення](./getting-started.md). |

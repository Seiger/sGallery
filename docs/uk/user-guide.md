# Посібник редактора

## Додавання й порядок медіа

1. Відкрийте ресурс у менеджері Evolution CMS. Перейдіть до вкладки галереї або до іменованого блока, який призначено шаблону.
2. Завантажте фото або виберіть наявний файл із бібліотеки, якщо роль це дозволяє. Для відео скористайтеся дією YouTube. Завантаження файлів доступне в інтеграціях із відповідним розділом.
3. Перетягніть записи в потрібному порядку й перевірте фото в попередньому перегляді.

## Підписи й видалення

У формі редагування заповніть альтернативний текст, назву, опис або посилання. Якщо підключено sLang, заповніть потрібні мовні вкладки. Для змістових зображень додайте alt, який допоможе зрозуміти їх без перегляду.

Видалення завантаженого запису видаляє його файл. Відв’язування запису зі спільної бібліотеки зберігає оригінал.

Якщо вкладки або кнопки немає, перевірте [призначення шаблону й права](./configuration.md#manager-gallery-permissions).

# Fehlerbehebung

- **Die Galerie fehlt:** Prüfen Sie die Vorlage und die Rolle unter [Konfiguration](./configuration.md).
- **Datei abgelehnt:** Prüfen Sie den Inhalt, die Dateiendung und die Upload-Einstellungen von Evolution CMS.
- **Das Original wird angezeigt:** Prüfen Sie den Decoder, das Ausgabeformat sowie den sTask-Runner bei langsamen Bildern.
- **Composer scheitert unter PHP 8.6:** Verwenden Sie die in [Erste Schritte](./getting-started.md) verlinkte Evolution-Version.
